# S3 Updater Hosting

S3 can host the update manifest and APK files for the in-game updater.

## Simple Test Setup

For fast testing, use a public-read S3 bucket or CloudFront distribution.

The app should point to:

```text
https://YOUR_UPDATE_BASE_URL/updates/latest.json
```

The manifest points to:

```text
https://YOUR_UPDATE_BASE_URL/releases/v0.0.9/com.puredalek.samandem-v0.0.9-release.apk
```

## GitHub Secrets

Add these repository secrets:

```text
AWS_ACCESS_KEY_ID
AWS_SECRET_ACCESS_KEY
AWS_REGION
S3_BUCKET
UPDATE_BASE_URL
```

`UPDATE_BASE_URL` should be the public HTTPS base URL for the bucket or CloudFront distribution, without a trailing slash.

Examples:

```text
https://my-bucket.s3.us-east-1.amazonaws.com
https://updates.example.com
```

## Security

Do not put AWS keys inside the APK.

If the bucket is public, anyone with the URL can download the APK. That is fine for quick testing, but not secure.

For private distribution, use one of these:

- CloudFront signed URLs.
- A small Cloudflare Worker or Lambda/API Gateway that checks a tester code and returns a temporary URL.
- S3 presigned URLs generated by a trusted backend.

The app should only know the manifest URL. It should not know AWS secrets.

## Workflow

`.github/workflows/android-s3-release.yml` builds the APK on tags and uploads:

```text
s3://S3_BUCKET/releases/vX.Y.Z/com.puredalek.samandem-vX.Y.Z-release.apk
s3://S3_BUCKET/updates/latest.json
```

Tag a release to publish:

```text
git tag v0.0.9
git push origin v0.0.9
```
